# Frontend

Angular application of the portfolio, generated with [Angular CLI](https://github.com/angular/angular-cli) version 22.0.4.

Setup, start commands, environment variables and deployment are described in the [root README](../README.md).

## Commands

```bash
npm start           # development server (generates the environment file first)
npm run build       # production build, requires PORTFOLIO_API_URL
npm test            # unit tests with Vitest
ng generate component component-name
```

Build artifacts are written to `dist/`. For more information on the Angular CLI, see the [Angular CLI Overview and Command Reference](https://angular.dev/tools/cli).
